# Shawro AI 桌面应用

一个基于 **DeepSeek API** 的桌面 AI 聊天应用，使用 Python + Flask + pywebview 构建，支持 macOS 和 Windows 双平台打包。

界面采用深色主题，提供流式对话、会话管理、代码块增强、图片/附件上传、工作区文件管理等丰富的聊天功能。

## 功能特性

| 类别 | 功能 |
|------|------|
| **对话** | SSE 流式输出、多轮上下文对话、代码高亮（highlight.js）、Markdown 渲染 |
| **会话管理** | 新建/删除会话、历史会话列表、会话标题自动生成 |
| **续写** | 基于 `finish_reason` 精确判断，回答被截断时显示"继续生成"按钮（单次动作，不会死循环） |
| **附件** | 图片/文本文件上传，图片点击可预览、可保存，附件随会话持久化 |
| **代码块** | 复制 / 下载 / 保存到工作区，工具栏悬浮在代码块顶部（滚动时始终可见） |
| **工作区** | 选择工作区目录、浏览文件、删除文件、AI 生成代码可直接保存到工作区 |
| **聊天索引** | 客户消息索引面板，点击跳转定位，滚动时高亮当前消息 |
| **交互优化** | 一键回到底部、用户消息绿色气泡 + 复制、文本可选中复制 |
| **配置** | 自定义 API 地址、API Key、模型选择（chat / reasoner / vl 多模态）、余额查询 |

## 技术架构

```
┌─────────────────────────────────────────────┐
│              pywebview 窗口                  │
│  ┌───────────────────────────────────────┐  │
│  │         index.html（前端界面）          │  │
│  │  Tailwind + Marked + highlight.js     │  │
│  └───────────────┬───────────────────────┘  │
│                  │  HTTP / SSE              │
│  ┌───────────────▼───────────────────────┐  │
│  │        Flask（后端 app.py）            │  │
│  │  路由 + API + 文件/工作区操作           │  │
│  └───────────────┬───────────────────────┘  │
│                  │                          │
│  ┌───────────────▼───────────────┐          │
│  │   SQLite（会话与消息持久化）     │          │
│  └───────────────────────────────┘          │
└─────────────────────────────────────────────┘
                    │
                    ▼
         DeepSeek API（流式接口）
```

- **前端**：原生 HTML + Tailwind CSS（本地静态资源）+ Marked（Markdown 渲染）+ highlight.js（代码高亮）
- **后端**：Flask 提供页面和 REST API，waitress 作为生产级 WSGI 服务器
- **桌面壳**：pywebview 提供原生窗口（含系统文件对话框、剪贴板等能力）
- **存储**：SQLite 本地数据库，会话和消息（含附件）持久化

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用（开发模式）

```bash
python app.py
```

启动后会自动弹出桌面窗口。首次使用需在左侧边栏填入：
- **API 地址**：默认 `https://api.deepseek.com/v1/chat/completions`
- **API 密钥**：你的 DeepSeek API Key
- **模型**：`deepseek-chat`（通用）/ `deepseek-reasoner`（推理）/ `deepseek-vl`（多模态）

### 3. 纯浏览器模式（可选）

如果只想用浏览器访问网页界面（不使用桌面窗口），可以设置环境变量后只启动 Flask 服务，用浏览器打开 `http://127.0.0.1:5000`。

> 注意：目录选择、系统保存对话框、剪贴板兜底等功能依赖桌面窗口环境，纯浏览器模式下这些功能不可用。

## 使用教程

### 基础对话

1. 在底部输入框输入消息，按 **Enter** 发送（**Shift + Enter** 换行）。
2. AI 回复以**流式**方式逐字显示。
3. 回复中的代码块会自动高亮，并带「复制 / 下载 / 保存到工作区」工具栏。

### 会话管理

- 左侧「历史对话」列出所有会话，点击切换。
- 点击会话右侧的删除按钮可删除该会话。
- 新建会话会自动生成标题（取首条消息前 20 字）。

### 续写（继续生成）

- 当 AI 回复因达到最大长度被截断时，回复底部会出现「继续生成 ⬇️」按钮。
- 点击后 AI 从上次中断处继续，补完一段即停止（不会无限循环）。

### 上传图片 / 附件

- 点击输入框旁的附件按钮，选择图片或文本文件。
- 图片会以缩略图显示在消息中，**点击图片可放大预览**，预览中可**保存**到本地。
- 附件会随会话保存，重新打开会话后仍可查看。

### 工作区（代码文件管理）

- 在左侧「工作区」点击 📂 按钮选择本地目录。
- 工作区会显示目录下的文件列表，可直接**删除**文件。
- AI 生成的代码块点击「保存到工作区」，可把代码写入工作区目录（需先选择目录）。

### 聊天索引（定位客户消息）

- 聊天区右下角点击列表图标，展开「聊天索引」面板。
- 面板列出当前会话所有用户（客户）消息，点击可**跳转定位**到对应气泡。
- 滚动聊天区时，索引中**当前正在查看的消息会自动高亮**。

### 其他快捷操作

- 聊天区右下角「↓」按钮一键回到最新消息底部。
- 用户消息悬停可**复制**（绿色气泡）。
- 聊天内容（含代码）可直接**鼠标选中复制**。
- `Ctrl/Cmd + K` 快速聚焦输入框。

## 打包发布

### macOS 打包

```bash
./build.sh
```

生成 `dist/Shawro AI.app`（带长颈鹿图标）。

### Windows 打包

在 **Windows 机器**上运行：

```bat
build.bat
```

生成 `dist\Shawro AI.exe`（带长颈鹿图标）。

### 用 GitHub Actions 云端打包 Windows 版（无需 Windows 机器）

本项目已配置 `.github/workflows/build-windows.yml`，可以借助 GitHub 云端直接打包 `.exe`：

1. 把代码推送到 GitHub 仓库的 `main` 分支（或手动触发）。
2. 打开仓库的 **Actions** 页面，运行「Build Windows EXE」工作流。
3. 打包完成后，在运行记录底部的 **Artifacts** 里下载 `ShawroAI-Windows`（内含 `.exe`）。
4. 如果推送的是 `v` 开头的 tag（如 `v1.0.0`），会自动创建 **Release** 并附带 `.exe` 供下载。

> **注意**：PyInstaller 不支持跨平台打包，`.exe` 必须在 Windows 环境打包，`.app` 必须在 macOS 环境打包。GitHub Actions 的 `windows-latest` runner 正好解决了没有 Windows 机器的问题。

### 打包说明

- 图标文件：`static/icon.icns`（macOS）、`static/icon.ico`（Windows）、`static/icon.png`（网页 favicon）。
- 打包时会自动把 `templates/` 和 `static/` 目录打进可执行文件。

## 配置说明

### 数据库

- 开发模式：数据库保存在项目目录下 `chat_history.db`。
- 打包模式：数据库保存在用户主目录 `~/deepseek_chat_history.db`（跨版本更新不丢数据）。

### 配置文件

- API 配置保存在用户主目录 `~/.deepseek_desktop_config.json`。

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `DEEPSEEK_PORT` | 后端服务端口 | `5000` |

## 常见问题

### 1. 提示 `Connection is a "hop-by-hop" header` 报错

这是 WSGI 服务器（waitress）不允许应用设置 `Connection` 头导致的，已在代码中修复，确保使用最新代码即可。

### 2. 图片 / 附件不显示

附件随消息持久化到数据库。如果旧版本产生的会话只有 `[图片/附件]` 占位符，是因为旧版未保存附件内容，新建的会话不受影响。

### 3. 点击"继续生成"没反应或一直循环

续写逻辑基于 `finish_reason === 'length'` 判断，且为单次动作。若模型返回非标准字段导致不触发，请确认使用的是 DeepSeek 官方 API。

### 4. 目录选择 / 保存对话框不可用

这些功能依赖 pywebview 桌面窗口。纯浏览器模式下（直接访问 127.0.0.1）不可用，需以桌面应用方式运行。

### 5. 打包后数据库/图标在哪

- 数据库：用户主目录下的 `deepseek_chat_history.db`
- 图标：已内嵌到可执行文件，无需额外文件
